### 📖 Guía de los campos del JSON (Open-Meteo)
Para que el motor de IA de Ika Travel funcione, extraeremos los datos de estas secciones:

- **Cabecera (Metadatos):** Muestra `latitude`, `longitude`, la diferencia horaria (`utc_offset_seconds` como -18000 que es GMT-5 para Perú) y la elevación.
- **`current_units` y `hourly_units`:** Indican qué medidas se están usando (ej. `°C` para temperatura, `km/h` para viento).
- **`current`:** El clima en el segundo exacto en que se consultó la API.
- **`hourly`:** **¡La sección más importante!** Es un arreglo (lista) de 24 posiciones que tiene el pronóstico para cada hora del día de hoy. 
  - `time`: Las 24 horas del día.
  - `temperature_2m`: La temperatura a 2 metros del suelo para cada hora.
  - `relative_humidity_2m`: La humedad para cada hora.
  - `wind_speed_10m`: El viento a 10 metros del suelo (clave para saber si hacer sandboarding).
  - `uv_index`: El índice UV para cada hora.

Si un usuario planifica una actividad a las **10:00 AM**, el backend buscará en la posición `10` de estos arreglos (`hourly["temperature_2m"][10]`) y le pasará ese dato a la IA.
