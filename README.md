# Ika Travel & Experience

Plataforma inteligente de turismo para la región de Ica, basada en Arquitectura Orientada a Servicios (SOA) y Microservicios. Incluye geolocalización, recomendaciones mediante IA basadas en clima en tiempo real, traducción bidireccional y botón SOS. 

Proyecto universitario desarrollado para el curso de Diseño e Implementación de Arquitectura Empresarial (Ciclo VIII).

## Estructura del Repositorio
Este repositorio contendrá el código fuente tanto para el Frontend (Aplicativo Móvil) como para el Backend (Microservicios).
